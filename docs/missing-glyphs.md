# 缺字补丁

本派生版本补充了小方块项目界面和学习内容中实际遇到的缺字。补丁覆盖 8px、10px、12px 的等宽和比例宽度版本，并沿用仓库现有的像素字形来源与字面网格。

界面必需字形包括：`›`、`−`、`灬`、`纟`、`饣`、`㇏`、`讷`。

同时补充了学习内容和拼音完整性所需的字形：`峤`、`曈`、`鹂`、`鹭`、`爫`、`犭`、`礻`、`≠`、`ɡ`、`ˉ`、`ˊ`、`ˇ`、`ˋ`、`ế`、`ề`、`ḿ`。`氵` 的 10px 字形也使用了专门的三点水像素字形，避免沿用过粗的后备图。

这些字形由 `assets/patch-glyphs/` 参与常规构建；Demo 页面包含一行覆盖样例，方便在不同字号和宽度模式中目测检查。
